# jenniferduka.com

Static recreation of [jenniferduka.com](https://jenniferduka.com/) for GitHub Pages.

## Stack

- HTML, CSS, JavaScript only
- No build tools, no Framer runtime, no React

## Local

Open `index.html` in a browser, or serve the folder:

```bash
python3 -m http.server 8080
```

## Deploy

Enable GitHub Pages from the repository root (`/` / `main`).
